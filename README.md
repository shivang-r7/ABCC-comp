## 🚀 How to Run Locally

You do not need to install heavy npm packages! The project is built with zero build friction:

### Option 1: Double Click
Simply double-click `index.html` to open it in your default web browser (Chrome, Edge, Firefox, Safari).

### Option 2: Local HTTP Server (Python or Node)
If you prefer running a local server:

**Using Python:**
```bash
python -m http.server 3000
```
Then visit: `http://localhost:3000`

**Using Node / npx:**
```bash
npx serve .
```

## 🌐 Instant 1-Click Deployment

- **GitHub Pages**: Push this directory to a GitHub repository, go to **Settings > Pages**, and select the `main` branch.
- **Vercel**: Import the GitHub repo into Vercel or run `npx vercel` in this folder.
- **Netlify**: Drag and drop this folder directly into [Netlify Drop](https://app.netlify.com/drop).
