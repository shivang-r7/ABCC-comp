From Textbook Syllabi to High-Performance Code

When I entered my Bachelor of Computer Applications (BCA) program, I immediately noticed a common pitfall: students memorizing syntax just to pass semester exams. I chose the opposite path.

I treated the curriculum — Relational Database Design, Memory Management, Operating Systems, Computer Networks, and Object-Oriented Principles — as sacred engineering foundations. Then, I spent my nights testing their limits in the modern ecosystem.

When we studied concurrency in theory, I wrote multithreaded workers in Rust. When we studied database schemas, I deployed containerized PostgreSQL instances with pgvector for semantic search. When we studied user interfaces, I crafted responsive web applications using Next.js 14 & Tailwind CSS.

AetherFlow — Real-Time Collaborative Canvas

An infinite digital whiteboard allowing hundreds of concurrent engineers to sketch diagrams, synchronize code snippets, and collaborate with sub-50ms vector updates. Engineered with an asynchronous Rust backend microservice to handle high-frequency delta synchronization without garbage collection spikes.

// Key Architecture Win:
• Custom Spatial Indexing (R-Tree) for instant viewport culling
• Actix-Web + Redis Pub/Sub for distributed socket clustering
TypeScript Rust Next.js 14 Redis
AI • Python • pgvector Semantic RAG

NeuroQuery — AI Document Intelligence & Search

An intelligent enterprise knowledge engine capable of digesting complex technical PDFs, source code repos, and legal documents. Features semantic cosine search with recursive token chunking and streaming conversational citations using FastAPI and pgvector.

// Key Architecture Win:
• Hybrid Search: Combines BM25 keyword matching with dense embeddings
• Sub-second response streaming via Server-Sent Events (SSE)
Python FastAPI PostgreSQL LangChain
Rust • TCP Sockets • Concurrency 180k+ RPS

VeloCache — High-Throughput Key-Value Engine

A bespoke in-memory database built in pure Rust to explore low-level network programming, concurrent lock-free data structures, and persistent disk journaling. Includes an interactive CLI client and custom binary protocol parsing.

// Key Architecture Win:
• Sharded Hash Table with zero global lock contention
• Asynchronous Append-Only File (AOF) background worker
Rust Tokio TCP Protocol Benchmarking
Go • React • GraphQL High-Concurrency

DevPulse — Git Velocity & Team Telemetry

A high-throughput GitHub repository analytics engine written in Go that ingests commit histories, PR lifecycles, and code churn trends. Outputs beautiful interactive SVG velocity heatmaps in a modern React interface.

// Key Architecture Win:
• Concurrent Go worker pipelines with exponential backoff on GitHub APIs
• Zero external database dependency: uses embedded SQLite WAL mode
